# Instagram Deco

Estilo de texto **Deco** de las historias de Instagram.

| | |
|---|---|
| Fuente | Instagram Deco Regular |
| Tipo | Original |
| Diseño | Colophon Foundry para Meta |
| Archivos | `InstagramDeco-Regular.otf` |

## Origen

Extraída del paquete de la app; el nombre interno coincide con el del estilo.

## Verificación

- Mismas letras en la comparación visual (D, e con travesaño recto, c, o).
- La etiqueta del menú es demasiado pequeña para medir IoU con fiabilidad.
