# Instagram Editor

Estilo de texto **Editor** de las historias de Instagram.

| | |
|---|---|
| Fuente | Instagram Editor Regular |
| Tipo | Original |
| Diseño | Colophon Foundry para Meta |
| Archivos | `InstagramEditor-Regular.otf` |

## Origen

Extraída del paquete de la app; el nombre interno coincide con el del estilo.

## Verificación

- Etiqueta «Editor» del menú: IoU 0,604 (Courier New: 0,092).
- Mismas formas en la comparación visual (E, d, i con remate, r).
