# Instagram Handwritten

Estilo de texto **Handwritten** de las historias de Instagram.

| | |
|---|---|
| Fuente | Instagram Signature Regular |
| Tipo | Original |
| Diseño | Colophon Foundry para Meta |
| Archivos | `InstagramSignature-Regular.otf` |

## Origen

Extraída de un IPA de Instagram (build de terceros con la fuente cacheada). Instagram no la incluye en el paquete de la app: la descarga la primera vez que se usa el estilo y la guarda en una zona privada del dispositivo.

## Verificación

- Manuscrita enlazada con formas contextuales OpenType (`init`/`medi`/`fina`): los programas que aplican esas reglas enlazan las letras solos.
- IoU con la captura «hola mundo», con shaping aplicado (HarfBuzz): **0,881** (Cosmopolitan Script: 0,151).
- Corrige una identificación previa como Cosmopolitan Script, hecha a ojo.
