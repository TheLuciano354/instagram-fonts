# Instagram Headline

Estilo de texto **Headline** de las historias de Instagram.

| | |
|---|---|
| Fuente | Advercase Regular |
| Tipo | Original |
| Diseño | — |
| Archivos | `Advercase-Regular.otf` |

## Origen

Incluida en el paquete de Instagram para iOS (v453).

## Verificación

- Comparación letra a letra con 5 grupos de capturas: IoU **0,97–0,98**.
- La palabra completa da menos porque Instagram aprieta el tracking un 2–4 %; los glifos son idénticos.
- En los programas aparece como **Advercase**, no como «Instagram …».
