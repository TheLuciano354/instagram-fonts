# Instagram Modern

Estilo de texto **Modern** de las historias de Instagram.

| | |
|---|---|
| Fuente | Instagram Sans Condensed |
| Tipo | Original |
| Diseño | Colophon Foundry para Meta |
| Archivos | `InstagramSansCondensed-Regular.otf`, `InstagramSansCondensed-Light.otf`, `InstagramSansCondensed-Medium.otf`, `InstagramSansCondensed-Bold.otf` |

## Origen

Extraída del paquete de Instagram para iOS (v429).

## Verificación

- Las formas coinciden con las capturas, incluidas la `y`, la `k` y el `7`.
- Grosor del trazo de la H respecto a su altura: captura 0,5601 · Regular 0,5595 (Light 0,5238, Medium 0,5929, Bold 0,6238).
- El estilo usa el peso **Regular**; Light, Medium y Bold se incluyen como familia completa.
