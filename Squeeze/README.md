# Instagram Squeeze

Estilo de texto **Squeeze** de las historias de Instagram.

| | |
|---|---|
| Fuente | Instagram Squeeze Black |
| Tipo | Original |
| Diseño | Colophon Foundry para Meta |
| Archivos | `InstagramSqueeze-Black.otf` |

## Origen

Extraída de un IPA de Instagram (build de terceros con la fuente cacheada). Instagram no la incluye en el paquete de la app: la descarga la primera vez que se usa el estilo y la guarda en una zona privada del dispositivo.

## Verificación

- IoU con la captura «HAMBURGUESA 1234567890»: **0,845** (Instagram Sans Condensed Bold: 0,318). La cifra es algo menor por la baja resolución de la captura.
- Etiqueta «Squeeze» del menú de estilos: 0,820 frente a 0,339.
