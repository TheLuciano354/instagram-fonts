# Instagram Strong Android

Estilo de texto **Strong Android** de las historias de Instagram.

| | |
|---|---|
| Fuente | Instagram Strong Android ExtraBold Italic |
| Tipo | Original |
| Diseño | Julieta Ulanovsky |
| Archivos | `InstagramStrongAndroid-ExtraBoldItalic.ttf` |

## Origen

Es **Montserrat ExtraBold Italic**, extraída del paquete de Instagram para iOS (v429). Se distribuye con el nombre normalizado; glifos, métricas y kerning sin modificar.

## Verificación

- Archivo idéntico al que usa la app.
- Las capturas coinciden letra a letra con alturas dentro de 1 px.
