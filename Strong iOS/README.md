# Instagram Strong iOS

Estilo de texto **Strong iOS** de las historias de Instagram.

| | |
|---|---|
| Fuente | Instagram Strong iOS Heavy Italic |
| Tipo | Original |
| Diseño | Adrian Frutiger / Akira Kobayashi (Linotype) |
| Archivos | `InstagramStrongiOS-HeavyItalic.ttf` |

## Origen

Es **Avenir Next Heavy Italic**, la fuente del sistema de iOS que usa la app. Copia de `/System/Library/Fonts/Avenir Next.ttc` con el nombre normalizado.

## Verificación

- Ángulo de la cursiva: 10,02° en las capturas · 10,04° en la fuente.
- Alturas de todas las letras dentro de 0,2–1 px.
- Una reconstrucción independiente desde capturas coincidía en un 97,5 % de la tinta.
